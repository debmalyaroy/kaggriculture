### Module 1: Replay Subgame Miner (Offline Rust / DuckDB)

The purpose of Module 1 is to build empirical payoff matrices for competitive liquidation rather than guessing game-theoretic parameters.

* **State Reconstruction from Traces:** Module 1 scans historical top-tier replays. It parses the opponent's public tile grid every step to count completed harvests (e.g., when a mature melon tile with `yield_units: 6` becomes empty, increment harvest by 6) and subtracts observed public market sales (`Δ market inventory + town drain − our own sales`).


* **Collision Window Extraction:** The miner identifies two distinct operational regimes:
1. *Mid-game Tranching (Days 6–27 / Steps 144–648):* Instances where both players hold $\ge 20$ units of a sensitive good (Strawberry, Melon, Milk, Wool).


2. *Endgame Liquidation Standoff (Days 27–30 / Steps 648–711):* Instances where both players hold massive inventory reserves heading into the final liquidation window.




* **Payoff Quantification:** For each identified collision, Module 1 categorizes the step actions of both players into discrete strategies: $S \in \{\text{Hold}, \text{Tranche } (10\text{--}12 \text{ units}), \text{Dump All}\}$. It calculates the terminal bank impact ($\Delta \text{Coin}$) resulting from concurrent 1-by-1 engine price degradation to establish the payoff matrix $A$.



---

### Module 2: Mixed-Strategy Nash Equilibrium Solver (Offline Rust)

Because pure deterministic strategies are mapped by reactive opponents and lineage classifiers, Module 2 solves for the Mixed Strategy Nash Equilibrium (MSNE) over the empirical payoff matrices generated by Module 1.

* **Subgame Formulation:** For each sensitive commodity $c \in \{\text{Melon}, \text{Wool}, \text{Milk}, \text{Strawberry}\}$ across discrete price bins, the game is framed as a zero-sum bimatrix:

$$U(\sigma_1, \sigma_2) = \sigma_1^T A \sigma_2$$



where $\sigma_1, \sigma_2$ are probability distributions over actions $\{\text{Hold}, \text{Tranche}, \text{Dump}\}$.


* **Endgame Standoff Resolution:** In the Day 27–30 liquidation standoff, pure waiting causes a Day 29/30 coin-toss crash, while deterministic dumping is front-run by one step. The solver calculates the indifference condition:



$$E[U(\text{Dump at } t)] = E[U(\text{Hold until } t+1)]$$



This yields a discrete probability distribution over activation thresholds:

$$P(\text{Sell Gate} = P_k) = p_k, \quad \sum p_k = 1$$


* **Binary Serialization:** The resulting strategy tables are serialized into a static binary `gt_matrix.bin` (or embedded directly into `rshell.json` and `preempt.json`), requiring zero runtime solving.

```rust
use crate::obs::Obs;
use std::collections::HashMap;

#[derive(Default, Clone)]
pub struct OpponentStateTracker {
    pub unliquidated_stock: HashMap<String, u32>,
    pub prev_tiles: Vec<Vec<Option<String>>>,
    pub prev_market_inv: HashMap<String, u32>,
}

impl OpponentStateTracker {
    pub fn update(&mut self, obs: &Obs, my_sales: &HashMap<String, u32>, town_drain: &HashMap<String, u32>) {
        let opp_id = 1 - obs.player;
        let opp_farm = &obs.farms[opp_id];

        // 1. Detect harvests by checking tile transitions from mature crop to None
        for y in 0..10 {
            for x in 0..10 {
                // If previous tile had yield and current tile is empty -> Harvested!
                // Increment unliquidated_stock based on known crop yield rules
            }
        }

        // 2. Exact recovered opponent sales formula from architecture spec:
        // Delta market inventory + town drain - our own sales
        for (item, &curr_inv) in &obs.market.inventory {
            let prev_inv = *self.prev_market_inv.get(item).unwrap_or(&curr_inv);
            let drain = *town_drain.get(item).unwrap_or(&0);
            let my_sold = *my_sales.get(item).unwrap_or(&0);

            let net_change = curr_inv as i32 - prev_inv as i32;
            let opp_sold = (net_change + drain as i32 - my_sold as i32).max(0) as u32;

            if let Some(stock) = self.unliquidated_stock.get_mut(item) {
                *stock = stock.saturating_sub(opp_sold);
            }
        }

        // Cache state for next step
        self.prev_market_inv = obs.market.inventory.clone();
    }
}

```

Update `crates/agent/src/layers/preempt.rs` and its configuration `preempt.json` to eliminate the Day 27–30 losses:

* **Extend Active Window:** Change the configuration parameter `to: 647` to `to: 711` in `preempt.json`.


* **State-Based Trigger:** If the group classification is `COPY` or `PARTIAL` (Layer 1) and `OpponentStateTracker` indicates the opponent's unliquidated premium stock exceeds 15 units:


1. The agent samples an activation threshold from the offline MSNE distribution using a deterministic per-game secret seed.


2. If the market price $\ge \text{Gate}_{\text{sampled}}$ or if step $\ge 680 + \text{Jitter}$, `preempt.rs` asserts an immediate high-priority `SELL` order at slot 0 of the market order list.

```rust
// Inside crates/agent/src/layers/preempt.rs
pub fn evaluate_game_theoretic_preempt(
    step: usize,
    group: u8, // 0: DIFFERENT, 1: PARTIAL, 2: COPY
    projected_shed: &HashMap<String, u32>,
    tracker: &OpponentStateTracker,
    market_prices: &HashMap<String, u32>,
    game_seed_entropy: f32, // Deterministic per-game hash to prevent tape mapping
) -> Vec<MarketOrder> {
    let mut preempt_orders = Vec::new();

    // Fix: Allow layer to run up to step 711 (previously locked at 647)
    if step < 144 || step > 711 {
        return preempt_orders;
    }

    // High threat detection: COPY or PARTIAL rivals holding > 15 premium units
    let is_clone_rival = group == 1 || group == 2;

    for &item in &["WOOL", "STRAWBERRY", "MILK", "MELON"] {
        let opp_holdings = *tracker.unliquidated_stock.get(item).unwrap_or(&0);
        let my_stock = *projected_shed.get(item).unwrap_or(&0);

        if my_stock == 0 { continue; }

        let price = *market_prices.get(item).unwrap_or(&0);
        
        // Mixed-Strategy Threshold Sampling
        let msne_gate = if game_seed_entropy < 0.35 { 150 } else { 110 };

        let trigger_endgame_race = step >= 672 && (opp_holdings >= 12 || step >= 705);
        let trigger_midgame_race = price >= msne_gate && opp_holdings >= 15;

        if is_clone_rival && (trigger_endgame_race || trigger_midgame_race) {
            // Front-run: Place full projected stock at the front of the queue
            preempt_orders.push(MarketOrder::Sell {
                product: item.to_string(),
                quantity: my_stock,
            });
            break; // Maximize first order priority in simultaneous engine resolution
        }
    }

    preempt_orders
}
```
