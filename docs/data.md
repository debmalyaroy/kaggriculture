# Data

The repository carries **no data** (purged 2026-10-01). Everything below is regenerated by the tools and lands in
gitignored folders (`data/`, `models/`, `weights/`, `.local/`). Keep downloads within the Kaggle replay quota and the
disk budget: never download a whole daily episode dataset — read its manifest, rank, and pull individual episodes.

| Data | Folder | How to produce it |
|---|---|---|
| Our ladder games as tapes | `data/ladder/<sub>/tapes/`, `games.tsv` | `python python/ladder_pull.py --subs <ids>` |
| Top-team games as tapes | `data/top50/fetch/` | `python python/top50/fetch.py --top 50 --days 7` |
| Replay -> tape conversion | — | `python/replay_to_tape.py` (used by both pulls) |
| Daily datasets / corpus index | `data/slim/`, `data/corpus/` | `python python/delta.py` + `crates/corpus` (`corpus-extract`) |
| Tape sets for tournaments | `data/tapes/{top_all,leaders,hard,losses,...}` | `python/gm_top_tapes.py`, `refresh_top_tapes.py`, `loss_tapes.py`, `band_tapes.py` |
| Route library + chassis bases | `data/chassis/`, `configs/bases/*/routes.json` | `python/routes/` (gm_routes, build_bases, screen_routes, final_base), `chassis-repair`, `chassis-screen` |
| World bank (64 worlds) | `data/worlds/` | `src/kaggriculture/trackp/harness/realized.py` (`build_map`) |
| Public opponent agents | `data/winplan/field/`, `data/winplan/agents/` | `src/kaggriculture/winplan` / `python/field80.py` |
| Shells, endgame, policy weights | `weights/`, `configs/rshell`, `configs/endg` | `python/top50/train_shell.py`, `python/rshell/train.py`, `python/endg/train.py`, `python/learn/` |
| Original pipeline data/models | `data/`, `models/` | `python -m kaggriculture.pipeline.autopilot` (fetch -> train -> build -> gate) |
| Built agents / graphs | `agents/` | `python -m kaggriculture.agentbuild.*` (only `agents/v1_heuristic.py` is source) |
| Builds | `data/builds/<name>/` | `python python/release/pack_submission.py` |
| Engine pin | `models/engine_version.json` | `scripts/engine_swap_1327.py` (defaults to 1.32.6 when absent) |

Compile-time assets that **are** kept in the repo: `crates/agent/data/v92_lib.bin` and
`rustengine/v62/crates/agent/data/v92_lib.bin` (embedded with `include_bytes!`). The legacy `kagg` bandit/trackp lanes
read their tapes at run time from `$KAGG_TAPE_DIR` (default `rustengine/tapes`) and `$KAGG_AGENTDATA_DIR` (default
`rustengine/agentdata`); missing files load as empty economies.
